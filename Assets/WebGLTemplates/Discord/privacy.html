プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-06

Multi Sweeper（以下「本ゲーム」）は、Discord Activity およびウェブブラウザで遊べるゲームです。本ゲームの開発チーム（以下「私たち」）は、利用者の個人情報を収集しません。

1. 収集する情報

  • 私たちは、Discord のユーザー名・ID・アバター・メッセージ・フレンド情報・ボイスチャンネルの情報など、Discord アカウントに関する情報を取得・保存しません。本ゲームは Discord の OAuth 認証を使用しません。
  • 本ゲームはアカウント登録、ランキング、チャット、広告、解析ツールを備えていません。

2. 技術的な情報

  • 本ゲームはクラウドサービス Cloudflare 上で配信されています。配信の過程で、Cloudflare が IP アドレスやアクセス日時などの技術的な情報を、同社の プライバシーポリシー に従って処理することがあります。私たちはアクセスログを記録・保存していません。Discord 経由で起動した場合、通信は Discord のプロキシを経由し、利用者の IP アドレスは配信サーバーに直接届きません。
  • 読み込みを速くするため、ゲームデータを利用者のブラウザ内（IndexedDB）にキャッシュします。このデータは利用者の端末内にのみ保存され、私たちには送信されません。

3. 外部サービス

  • クリア画面の共有ボタンは、X（旧 Twitter）の投稿画面を開きます。Discord 内では、外部リンクを開く前に Discord が確認を表示します。リンク先での情報の取り扱いは、各サービスのポリシーに従います。
  • Discord の利用には Discord のプライバシーポリシー が適用されます。

4. 情報の第三者提供・販売

私たちは利用者の情報を収集しないため、第三者への提供や販売は行いません。

5. データの削除

私たちは利用者の個人データを保持していません。ブラウザ内のキャッシュは、ブラウザのサイトデータ削除でいつでも消去できます。

6. 変更

本ポリシーを変更する場合は、このページで告知し、最終更新日を更新します。

7. お問い合わせ

GitHub Issues からご連絡ください。Issues は公開されるため、個人情報は書き込まないでください。

日本語版と英語版の内容に相違がある場合は、日本語版が優先します。

Multi Sweeper (the "Game") is a game playable as a Discord Activity and in a web browser. The Game's development team ("we") does not collect personal information from players.

1. Information we collect

  • We do not obtain or store any Discord account information, such as usernames, user IDs, avatars, messages, friends or voice channel data. The Game does not use Discord OAuth.
  • The Game has no accounts, leaderboards, chat, advertising or analytics.

2. Technical information

  • The Game is served from Cloudflare. In delivering it, Cloudflare may process technical information such as IP addresses and request times under its privacy policy. We do not record or store access logs. When launched in Discord, traffic goes through Discord's proxy and your IP address does not reach our server directly.
  • To load faster, game data is cached in your browser (IndexedDB). This stays on your device and is never sent to us.

3. Third-party services

  • The share button on the clear screen opens a post page on X (formerly Twitter). Inside Discord, Discord asks for confirmation before opening external links. Those services handle data under their own policies.
  • Your use of Discord is governed by the Discord Privacy Policy.

4. Sharing or selling data

Because we do not collect player data, we do not share or sell it.

5. Data deletion

We hold no personal data about you. You can clear the browser cache at any time by deleting site data in your browser.

6. Changes

We will announce changes on this page and update the "Last updated" date.

7. Contact

Please contact us via GitHub Issues. Issues are public, so please do not post personal information.

If the Japanese and English versions differ, the Japanese version prevails.
